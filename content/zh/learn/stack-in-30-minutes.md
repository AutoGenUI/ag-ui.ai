## 学习成果

你将能在比较 API 之前，先把一项生成式 UI 技术放到正确的生态层级。

## 学习路线

1. 从[生态图谱](/zh/map)开始，跟踪一个事件如何从 Agent 到达渲染组件。
2. 阅读 AG-UI、A2UI 和 MCP Apps 页面，观察它们解决的是不同架构问题。
3. 使用比较矩阵，把协议与渲染框架分开判断。
4. 完整运行一次事件实验室，包括用户确认步骤。

## 检查点

解释为什么 AG-UI 与 A2UI 可以组合，而不是互相替代。答案若同时提到交互传输和声明式 UI 意图，说明心智模型已经建立。
