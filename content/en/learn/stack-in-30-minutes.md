## Outcome

You will be able to place a Generative UI technology at the correct layer before comparing APIs.

## Route

1. Start with the [ecosystem map](/en/map) and follow one event from an agent to a rendered component.
2. Read the AG-UI, A2UI, and MCP Apps pages. Notice that they answer different architectural questions.
3. Use the comparison matrix to separate protocols from renderer frameworks.
4. Run the event lab once, including the approval step.

## Checkpoint

Explain why AG-UI and A2UI can be combined without either one replacing the other. If your answer mentions interaction transport and declarative UI intent, the model is working.
