This baseline separates agent–frontend interaction, declarative UI, embedded host applications, and implementation frameworks. It deliberately describes Open-JSON-UI as an ecosystem-documented approach until an independent first-party specification can be verified.

Future updates will record upstream repository, documentation, license, maturity, and version changes without silently rewriting published guidance.
