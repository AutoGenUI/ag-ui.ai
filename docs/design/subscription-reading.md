# Subscription and RSS reading layout

The subscription page retains the newsroom's cream paper, ink-blue headings and restrained editorial typography. Desktop columns align at the top, so the RSS panel takes its content's height instead of stretching alongside the longer email form. On smaller screens, the panels form a single readable column.

The email form groups delivery language and address, selected topics, the main action, and a separate unsubscribe area. Status cards remain persistent and announce real server results. Clipboard feedback is local to RSS and does not change subscription state.

Each RSS card links to the actual published Chinese or English feed and exposes its public URL. Copy uses the browser clipboard only; if unavailable, selecting the address supports manual copying. The sidebar contains a two-step reading guide and the existing English compatibility feed.

Capacity and anonymous-tracking disclosures remain visible. Confirmed subscribers count toward the site's 250-place capacity; RSS does not consume a place. The daily email allowance and digest budget are unchanged. No backend, schedules, authentication, secret values or sending behavior changes are included.

`public/brand/rss-feed.svg` is an original code-native SVG created for this layout. It contains no external assets or scripts, and is decorative in the page.
