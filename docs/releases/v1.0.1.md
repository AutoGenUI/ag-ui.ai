# AG-UI.AI v1.0.1 发布回执

2026-10-13 用户明确授权 v1.0.1 标签、提交推送及更新部署。本记录初始阶段为发布候选；正式 tag、GitHub SHA、CI 和 Sites 对应版本在实际完成后补录。授权覆盖此前的等待发布门槛，但不代表新增邮箱收件成功证据。

## 相对 v1.0.0 的变化

- 调整下拉箭头留白；订阅页统一为介绍、容量、反馈、操作表单、取消/退订、隐私说明。
- 优化中英确认邮件和周报 HTML/纯文本，区分确认入口与管理/退订区域；移除误导性的返回填写按钮。
- 有效确认页实际可见且就绪时自动 POST 确认；GET、HEAD、SSR、预取不确认，取消/退订仍需主动操作。能执行页面 JavaScript 的扫描器仍可能触发确认，不声称防住全部扫描。
- 普通退订身份可以经新同意重新申请；保留新旧链接代际、历史、抑制、不确定提交与防重复投递。
- 仅 owner 精确匹配固定目标可释放历史测试角色，仍需普通用户自行申请确认；仅 owner 的诊断不发信、不改状态、不导出地址或签名。
- 申请超限显示 HTTP 429、明确未发新邮件及下一固定窗口时间；邮箱每日两次请求窗口在新加坡 08:00 切换，原计数与发送额度不变。

完整实现和既有验证见 [体验优化](../iterations/2026-10-13-subscription-polish.md)、[普通身份与布局](../iterations/2026-10-13-normal-subscription.md)、[申请限流](../iterations/2026-10-13-subscription-throttle.md)。本次版本提交仅修改工程元数据与公开说明，不再修改这些运行逻辑。

## 验证与保留边界

既有 v16 改进通过 119 项本地检查及 required CI；本次发布再次通过对应候选 CI 与 Sites 构建后才推送正式标签。保留原 920000 字节 JS 门槛，上一版实测 919961，仅余 39 字节；8 项 moderate 依赖问题与两项 lint 警告仍为已知限制。

保留原 Sites 项目、公开域名、D1、MCP、环境配置及两项任务。无 schema、DNS、发信开关、配额或订阅身份变更，不发送真实邮件、不读取私有邮箱或密钥、不新增付费 API。提供商 submitted、delivered 与读者实际收件仍分开记录。当前发布不自动补发被限流的申请，读者须在允许时间后重新提交。

GitHub 标签与 Sites 递增版本号是独立标识；正式标签固定在已验证的发布提交。后续补录文档可以领先该提交，但不得移动标签或混称为一次新部署。历史 v1.0.0 保持不变。
